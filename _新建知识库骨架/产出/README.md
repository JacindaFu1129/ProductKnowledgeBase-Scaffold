# 产出（按需生成的临时快照）

> ⚠️ 本目录**不是**长期维护对象。这里放的是**按具体场景、按需从知识库生成的一次性产物**，用完可留档或删除。

## 放什么
针对某个场景，从 `业务认知/`（+ `变更记录.md`）生成的视图，例如：
- **讲解 HTML**（新人培训）
- **跨业务说明稿**（对外/跨组说明）
- **交接清单**（人员交接）
- **回溯报告**（查历史问题）

## 规则
- **唯一事实来源是 `业务认知/`**，不是这里。产出与知识库不一致时，以知识库为准。
- 每个产物开头请注明：**用途 / 生成日期 / 基于哪些模块或版本**。
- 需要时**从知识库重新生成**，不在这里手工长期维护。
- 可随时清空本目录。
